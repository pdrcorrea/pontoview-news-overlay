Política de Privacidade

Esta página explica, de forma objetiva, como os dados pessoais necessários ao PontoView Studio são utilizados para fornecer, proteger e administrar o serviço.

Dados tratados

Podemos tratar dados de cadastro e autenticação, perfil, assinatura, configurações dos overlays, registros técnicos de acesso e informações enviadas ao suporte.

Finalidades

Os dados são utilizados para criar e proteger a conta, prestar o serviço contratado, administrar acesso e cobrança, oferecer suporte, prevenir abuso e cumprir obrigações legais aplicáveis.

Compartilhamentos

Dados podem ser processados por fornecedores necessários à operação do serviço, como infraestrutura, autenticação, banco de dados, e-mail e meios de pagamento, sempre de acordo com a finalidade correspondente.

Retenção

Os dados são mantidos pelo período necessário à prestação do serviço e, quando aplicável, pelo prazo exigido para cumprimento de obrigações legais, segurança e exercício regular de direitos.

Direitos do titular

Solicitações relacionadas a acesso, correção, informação, eliminação quando aplicável e demais direitos previstos na legislação podem ser encaminhadas para privacidade@pontoview.com.br.

Segurança

O PontoView Studio utiliza autenticação e mecanismos de controle de acesso para separar os dados de cada conta. As medidas de segurança são revisadas conforme o serviço evolui.

Atualizações

Esta política pode ser atualizada para refletir alterações no produto, nos fornecedores utilizados ou nas obrigações aplicáveis. A versão publicada nesta página será a referência vigente.
